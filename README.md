# Rocket CEA GUI

Local web app for NASA CEA rocket propulsion calculations, 3D nozzle/chamber CAD generation, and RocketPy export.

## Features

- **CEA Calculations** — Run NASA CEA rocket performance analysis (Isp, C*, chamber conditions) with species search
- **Nozzle CAD** — Generate conical and bell (Rao) nozzle profiles as OpenSCAD, STEP, and STL files
- **RocketPy Export** — Export motor configurations for RocketPy simulations

## Install

```bash
pip install -e .
```

With CAD generation (requires CadQuery):

```bash
pip install -e ".[cad]"
```

## Development

```bash
# Backend
pip install -e ".[dev]"

# Frontend
cd frontend && npm install

# Run backend
.venv/bin/uvicorn rocket_cea_gui.server:app --reload

# Run frontend dev server (proxies API to localhost:8000)
cd frontend && npx vite

# Build frontend for production
cd frontend && npx vite build
```

## Run

```bash
rocket-cea-gui serve
```

Opens browser to `http://localhost:8000`.

## Test

```bash
pytest tests/ -v
```

## Architecture

- **Backend:** FastAPI + Pydantic models + CEA solver service
- **Frontend:** React 18 + TypeScript + Vite + Tailwind v4 + Blueprint aesthetic
- **CAD:** CadQuery (STEP/STL) + OpenSCAD script generation
- **Export:** Jinja2 templates for RocketPy configs

## Project Structure

```
src/rocket_cea_gui/
  api/           # FastAPI routers (cea, cad, export)
  services/      # Business logic (cea_solver, cad_generator, cea_species)
  static/        # Built React SPA (generated by vite build)
  server.py      # FastAPI app + static serving
  cli.py         # CLI entry point

frontend/
  src/           # React components, pages, API client
  prototypes/    # HTML design prototypes

tests/           # pytest test suite
```
